# Documentation

- [Architecture](architecture.md) describes expression expansion, composition, adaptation, and map-to-existing behavior.
- [Migration guide](migration.md) covers moving from `Raffinert.Spec` and `Raffinert.Proj`.
- [EF Core integration](efcore-integration.md) is the public user guide for installation, operators, invocation expansion, directives, diagnostics and compatibility limits.
- [EF Core adapter architecture](architecture/efcore-adapter.md) is the internal reference for compiler integration, service lifetime, evaluation boundaries and technical decisions.
- [`experiments`](experiments/) contains historical EF engineering evidence and validation records; these are not public API instructions.
- [`design`](design/) contains historical planning and delivery records retained for design archaeology. These files are archival, not current product documentation.
